# Better Zen

Version: 1.0.0

Better Zen is a personal configuration for Zen Browser. It combines a custom
`userChrome.css` theme with optional modules for a domain-only address bar and
the KDE Plasma global menu on Flatpak installations.

## Features

- Floating, centered URL bar with a translucent background.
- Floating bookmarks pill, shown while the URL bar or bookmark controls are in use.
- Optional domain-only display while the URL bar is idle, with the full address
  available while it is expanded.
- macOS-style navigation controls and window-control styling.
- Compact vertical sidebar adjustments, tab audio indicators, and split-view styling.
- Optional KDE Plasma global-menu workaround for Zen Flatpak on Wayland.

The CSS is designed around the author's Zen profile and may require adjustment
for different toolbar layouts, screen sizes, or Zen releases.

## Repository contents

| Path | Purpose |
| --- | --- |
| `userChrome.css` | Main browser-chrome customization. |
| `zen-themes.css` | Zen-generated aggregate of installed theme CSS. Keep in sync with the profile. |
| `zen-themes/` | Source CSS and metadata for installed Zen themes. |
| `urlbar-domain-only/` | Optional AutoConfig module for trimming the idle URL bar to the registrable domain. |
| `kde-global-menu/` | Optional Flatpak workaround for the KDE Plasma global menu. |
| `VERSION` | Current project version. |
| `LICENSE` | MIT license. |

`zen-themes.css` is generated by Zen. Do not edit it manually; update it from
the browser profile when the installed theme set changes.

## Install the CSS configuration

1. In Zen, open `about:support` and use **Open Profile Folder** to locate the
   active profile. Its `chrome` directory contains `userChrome.css`.
2. Back up the existing `chrome` directory before replacing files.
3. Copy `userChrome.css` and the `zen-themes` files from this repository into
   that directory. If this repository is already cloned there, update it with
   `git pull --ff-only` instead of copying over the checkout.
4. Set `toolkit.legacyUserProfileCustomizations.stylesheets` to `true` in
   `about:config`.
5. Restart Zen Browser.

Example for an existing clone:

```sh
PROFILE_CHROME="/path/to/your/profile/chrome"
cp userChrome.css "$PROFILE_CHROME/"
cp zen-themes.css "$PROFILE_CHROME/"
cp -a zen-themes "$PROFILE_CHROME/"
```

## Optional: domain-only URL bar

The module displays the registrable domain while the URL bar is idle, for
example `github.com` for `https://github.com/user/repository`. When the URL bar
is expanded it preserves the full address. It uses Zen's `_zenTrimURL` hook;
CSS alone cannot transform the input value.

For Zen installed as a system Flatpak, run:

```sh
./urlbar-domain-only/install.sh
```

The installer requests administrator authentication to copy AutoConfig files
into the active Flatpak application deployment. Restart Zen after installation.
Zen updates replace the deployment, so rerun the installer after an update.
To remove the module, run `./urlbar-domain-only/uninstall.sh` and restart Zen.

AutoConfig runs privileged browser-chrome JavaScript and this module disables
the AutoConfig sandbox because it needs Firefox's `Components` APIs. Review the
source before installing it. The installer targets the Flatpak ID
`app.zen_browser.zen`.

## Optional: KDE Plasma global menu

See [`kde-global-menu/README.md`](kde-global-menu/README.md) for the optional
Flatpak and Wayland workaround. It changes Flatpak overrides and copies system
libraries into the user's Zen data directory.

## Adjust the layout

The floating-bar dimensions are defined near the beginning of `userChrome.css`:

```css
--floating-bookmarks-top: clamp(140px, 30vh, 320px);
--floating-bookmarks-height: 36px;
--floating-stack-gap: clamp(0px, 0.1vh, 2px);
--floating-bookmarks-max-width: min(92vw, 760px);
```

The main accent and translucent surface color is `#202326`.

## Compatibility

The current configuration was maintained on Zen Browser 1.24b on Linux using
the Flatpak package. CSS selectors and AutoConfig hooks are internal browser
interfaces and can change between Zen releases. Other platforms and toolbar
layouts are not guaranteed to work without changes.
